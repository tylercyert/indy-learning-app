# Roadmap

Work is tracked in [GitHub Issues](https://github.com/tylercyert/indy-learning-app/issues) under the milestone "First complete learning loop". This page is the map, not the tracker.

| Slice | Issue | What a learner can do when it lands |
|---|---|---|
| 1 Foundation | #1 (done, `41d745b`) | Nothing visible yet: contracts, rules, server, router shell |
| 2 First complete loop | #2 | State a goal, answer intake, get a course, finish the orientation lesson |
| 3 Skill tree | #3 | See the winding path, open nodes as they unlock, celebrate, keep a streak |
| 4 History and reuse | #4 | Get lessons that know what they already did; rename or re-roll the companion; keep going after a course |
| 5 Discovery and exploration | #5 | Start from an existing course; ask to go somewhere different mid-course |
| 6 Social | #6 | Pending the owners' brief |

Cross-cutting: structured-output limits (#7), component catalog expansion (#8), device QA (#9), dependency advisories (#10), license (#11), hosting (#12).

Details and acceptance criteria live on each issue and in `docs/implementation-plan.md`. Vocabulary is in `CONTEXT.md`.
